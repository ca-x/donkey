# Donkey Implementation Plan

> **For agentic workers:** Implement task-by-task and keep every task independently verifiable.

**Goal:** Build an auditable Rust replacement for the public KSpeeder feature set with safe multi-source acceleration, cache, responsive React management and automated delivery.

**Architecture:** Axum exposes a management/CONNECT listener and a Registry listener over one shared application state. SeaORM persists control-plane data in SQLite while immutable Blob bytes live in a content-addressed filesystem. React is compiled separately and embedded into the Rust binary.

**Tech Stack:** Rust/Tokio/Axum/Reqwest/SeaORM/SQLite; React/Vite/Mantine/TanStack Query; Docker Buildx/GitHub Actions.

**Spec:** `docs/SPEC.md`

## Global Constraints

- Default SQLite under `DONKEY_DATA_DIR`; immutable content cache under the same persistent root.
- Proxy inputs are hostile; private/insecure upstreams and CONNECT targets are fail-closed unless explicitly enabled.
- Frontend is embedded; production has no Node runtime.
- Mobile support starts at 375 px and uses 44 px touch targets.
- Never trade OCI digest correctness for concurrency.
